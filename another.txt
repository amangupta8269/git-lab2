Here is an additional set of interview questions **without answers**, covering Linux, Networking, and DevOps. They are organized by difficulty and topic, with practical commands and scenarios where relevant.

---

## 🟢 Beginner

### Linux Basics
1. What does the `pwd` command do? Give an example.
2. How do you create a new directory named `project` and immediately enter it?
3. What is the difference between `cp` and `mv`?
4. How do you display the first 10 lines of a file? How about the last 5 lines?
5. What command shows the current date and time in `YYYY-MM-DD` format?
6. How do you count the number of lines in a file?
7. What does `chmod 755 script.sh` mean? Who can do what?
8. How do you change the owner of a file to user `alice` and group `developers`?
9. What is the purpose of the `/etc/passwd` file?
10. How do you check the available disk space on all mounted filesystems?

### Basic Networking
11. What command shows your IP address and network interfaces?
12. How do you test if a remote host is reachable?
13. What is the difference between `localhost` and `127.0.0.1`?
14. How do you check which DNS server your system is using?
15. What port does HTTP use by default? HTTPS?
16. How do you display the routing table?
17. What command shows all active network connections?
18. How do you download a file from the internet using the command line?
19. What is the purpose of the `hostname` command?
20. How do you temporarily set an environment variable in bash?

### DevOps Basics

23. How do you check the status of a Git repository?
24. What is a CI/CD pipeline?

27. What is infrastructure as code? Give an example tool.
28. What is a web server? Name two common ones.
